# MetaEngine Desktop — единая Electron-система (R46)

Электрон-версия MetaEngine и ME2 больше не развиваются отдельно: это **одна система**.
Оболочка — тонкий нативный слой вокруг того же ядра, все механики ME2 живут в репозитории.

## Архитектура (умное слияние)

```
Electron main (PID-1 системы)
├── gateway.ts            встроенный мини-gateway — замена Caddy: XTransformPort-прокси (http+ws)
├── daemon-supervisor.ts  вечный супервизор: me2-daemon (bun) + Next UI (bun),
│                         backoff-рестарты, кооперация со стражем инкарнации (exit 13 → присоединение)
├── tab-registry.ts       TabRegistry (R41): панели-вкладки + нативные WEB-вкладки (браузер сам открывает сайт)
├── updater.ts            самообновление из GitHub (PatrickFrome/Compute) изнутри приложения
├── preload.ts            мост window.me2 (типы: src/lib/me2-desktop.ts)
└── main.ts               окно Mission Control v5 (тот же UI, что в браузере), меню, трей, IPC
```

## Запуск

```bash
# разработка (в корне репозитория должны жить daemon + UI как обычно)
cd desktop
bun install
bun run dev          # соберёт ts и запустит electron с --me2-dev

# production-сборка установщиков
bun run dist         # AppImage / NSIS / DMG в desktop/release/
```

Требуется `bun` в PATH (им запускаются daemon и UI). Переменные окружения:

- `ME2_ROOT` — корень репозитория (по умолчанию `../..` относительно оболочки);
- `ME2_BUN` — путь к bun (по умолчанию `bun`);
- `ME2_UI_URL` — URL UI (по умолчанию встроенный gateway `http://127.0.0.1:8137`);
- `ME2_GITHUB_TOKEN` — токен GitHub для проверки релизов (опционально).

## Порты

- `8137` — встроенный gateway (http + ws; XTransformPort → :3000 UI, :3040 socket.io,
  :3041 REST, :3042/:3043 стримы);
- `3000` / `3040` / `3041` — те же, что в веб-режиме.

## Что объединено

- **Главная панель «Браузер»** (R45 v5): список чат-агентов слева, живой сайт справа —
  как в старом браузере; в Electron это единственная MAIN-вкладка UI.
- **TabRegistry.create(role='SUPERVISOR')** (R41): нативное меню «Панели → Миссия»
  и программное создание вкладок — панели и WEB-сайты в одном реестре.
- **Операции флота**: только socket.io `agentchat:op` (REST POST снят в daemon v0.40.0) —
  оператор работает исключительно с открытыми чатами-агентами.
- **Вечность**: супервизор процессов оживляет daemon/UI; daemon внутри — свой страж
  инкарнации и watchdog; флот перерождается независимо.
- **Самообновление**: «Система → Проверить обновления» (GitHub Releases), staged-скачивание,
  применение после перезапуска (AppImage — мгновенная замена).
