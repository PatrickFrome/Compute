    63→
    64→**Файлы:** `src/supervisor-lifecycle-runtime-core.mjs` (1399 строк), `src/supervisor-keepalive.mjs`, `src/supervisor-bootstrap-keepalive.mjs`, `src/supervisor-mesh*.mjs` (4 файла), `src/browser-sentinel.mjs` v1.6.1, `src/host-resilience-runtime.mjs`, `src/browser-guardian-core.mjs` + `native/browser-guardian-scm/*.cpp` (Windows-сервис), тесты `supervisor-keepalive/continuity/mesh-*.test.mjs`.
    65→
    66→**Кто перезапускает супервизоров — 4 слоя:**
    67→1. **Keepalive-воскрешение в той же вкладке** (`SupervisorKeepalive`, мин. интервал 60 с): wake-сообщение `METAENGINE_SUPERVISOR_WAKE_V1` (`buildSupervisorWakeMessage`, supervisor-keepalive.mjs:180) печатается в composer той же беседы — «продолжай из durable state, не жди пользователя».
    68→2. **Rollover** (новая беседа при переполнении контекста): `METAENGINE_SUPERVISOR_ROLLOVER_V1` (epoch+1, previous_conversation). Защита от зомби: D-C5 (8 no-progress циклов → перезапрос на FRESH tab), D-C6 (троттлинг скана кандидатов 30 с), D-C7 (дрейн утечек), D-S1 (fallback по одному кандидату в том же процессе), и **ROLLOVER_DEFERRED_AUTO_RELEASE** — `DEFERRED_ROLLOVER_AUTO_RELEASE_MS = 15*60*1000` (стр. 25, актуация 1266-1284): operator-class rollover, припаркованный в DEFERRED (т.к. `approveRollover` не имеет ни одного вызыва — D-K8), через 15 минут самораспускается и открывает свежую вкладку. Это честный фикс «мёртвого супервизора на single-conversation install».
    69→3. **Crash sentinel** (`browser-sentinel.mjs`): worker-heartbeat ≤8 с, durable action-journal, successor-journal reconcile, restart policy, asar-unpack воркер.
    70→4. **Guardian** (`browser-guardian-core.mjs` + `native/browser-guardian-scm/`): план механик `START_CHILD / RESTART_EXACT_CHILD / ACTIVATE_CANDIDATE / ROLLBACK_CANDIDATE / ESCALATE_TO_SCM`; исполнение — C++ Windows SCM-сервис (`browser-guardian-scm-service.cpp`), WTS session broker (`browser-guardian-session-broker-wts-executor.cpp` — запуск в интерактивной сессии), update actuator (`browser-guardian-update-actuator.cpp`), owner-enrollment store/reconciler; всё под effect-journal (контрактные тесты `browser-guardian-*-effect-journal.test.mjs`).
    71→
    72→**Mesh:** `SupervisorMesh` строит реестр до 16 супервизоров (id = `sup_<sha256(url)[:24]>`, `metaengine.supervisor-mesh.state.v1`), `SupervisorMeshRuntime` — fenced reservation (`supervisor-mesh-fenced-reservation.mjs`), epoch fence, foreground-send через boundary-executor; синк в облако — RPC `h205f22_a2_supervisor_mesh_sync_v1` (index.ts:47, вызов из `upsertState`). Edge валидирует boundedMesh (supervisors ≤16, `authority_effect:false`, LOST→tab_id=null).
    73→
    74→**Связи:** keepalive/rollover пишут `supervisor_lifecycle`-плоскость state; mesh → `supervisor_mesh`-плоскость + MESH_SYNC_RPC; guardian → self-update контур (§8).

    84→**Полный жизненный цикл задачи:**
    85→```
    86→[roadmap/meta-оркестратор или оператор] → devos_fleet_enqueue (SQL-плоскость)
    87→→ ADMISSION: /v1/devos/cycle читает devos_environment_state_v1

    89→→ LEASE: /v1/devos/cycle → devos_fleet_reconcile_v1 → snapshot → fair-idle-кандидаты

    91→→ RUNNING: браузер вводит задачу в беседу агента; proof {prompt_sha256, conversation_url_sha256,
    92→   effect_state∈PROVEN_*} → /v1/devos/mark-running → devos_fleet_mark_running_v1 (CAS по generation/epoch)
    93→→ OBSERVE: #observeRunning — CAPTURE вкладки, stop-кнопка = GENERATING, tool-запросы агента
    94→   обслуживаются через /v1/commands/issue-tool (allowlist CAPTURE/READ_TRANSCRIPT/TAB_TELEMETRY/
    95→   SYSTEM_TELEMETRY/SCROLL/SEMANTIC_FOCUS)
    96→→ COMPLETE: #postCompletionWithReadback → /v1/devos/complete → devos_fleet_complete_v1
    97→   (состояния RESULT_READY/BLOCKED/COMPLETED/FAILED/AMBIGUOUS)
    98→→ AMBIGUOUS-write recovery: GET /v1/devos/tasks/{id}/status — readback-доказательство
    99→   (generation mismatch → no-retry), классы PRE_EFFECT_ABORTED / EFFECT_PROVEN →
   100→   devos_fleet_reconcile_ambiguous_v2
   101→```
   102→
   103→Ключевые функции клиента: `advanceTaskOutcomeFor` (devos-native-task-cycle-core.mjs:**1242**, вызов из **1169**) — never-throw мост терминального исхода в episodic-memory (learning write path); `#memoryBlockFor` — retrieval 5 верифицированных эпизодов в промпт (token_budget 900, кэш на lease); `#recordTaskOutcomeArtifact` — детерминированный artifact_id `devos.task-result.{task_id}.{gen}`; `runningObservationBudget(live)` = clamp(ceil(live/2), 4..16); D-C2: параллельный dispatch лизов, по-табовая сериализация.
