# Z.ai Chat Export — Chrome-расширение (Manifest V3)

Полноценный браузерный плагин: кнопка на странице чата + popup с выбором формата
+ хоткей. Скачивание — через `<a download>` прямо на странице (без лишних прав;
в MV3 service worker недоступен `URL.createObjectURL`, поэтому Downloads API
не используется). Хронологический порядок сообщений — «от начала до конца».

## Установка (режим разработчика, без Chrome Web Store)

1. Распакуйте `download/zai-chat-export-chrome-extension.zip` из корня репозитория
   (`/home/z/my-project/download/`) в постоянную папку
   (не удаляйте её — Chrome подгружает расширение именно оттуда),
   либо используйте уже распакованный каталог `chrome-extension/`.
2. Откройте `chrome://extensions`.
3. Включите переключатель **Developer mode** (справа сверху).
4. Нажмите **Load unpacked** → выберите папку с `manifest.json`.
5. Откройте чат на `https://chat.z.ai/` — справа внизу появится кнопка **Export chat**.

## Способы экспорта

| Способ | Формат |
|---|---|
| Кнопка «Export chat» на странице (клик) | Markdown |
| Кнопка на странице: Shift+клик | JSON |
| Кнопка на странице: Alt+клик | TXT |
| Иконка расширения → кнопки Markdown/JSON/TXT в popup | любой |
| Хоткей `Ctrl+Shift+Y` (Mac: `Cmd+Shift+Y`) | Markdown |

## Что умеет

- **Авто-прокрутка истории**: перед сбором прокручивает чат вверх и ждёт подгрузки
  старых сообщений (детект «история кончилась»: 10 шагов без роста). Позиция
  скролла восстанавливается.
- **Хронологический порядок** («от начала до конца»): два слоя — фактический
  DOM-порядок после полной загрузки истории + сортировка по timestamp, если
  парсится >=80% меток. Без этого lazy-load ломает порядок (старые блоки
  дописывались после новых). Итоговый режим указывается в метаданных (`order`).
- **Устойчивость к виртуализации DOM**: сообщения накапливаются в Map по
  стабильному id (`data-message-id` → дедупликация), даже если узлы удаляются
  из DOM при прокрутке.
- **Каскад селекторов** сообщений и эвристическое определение ролей
  User/Assistant (атрибуты → классы → flex-выравнивание).
- **Код-блоки** (`pre` + язык из `language-*`) и **временные метки**
  (`time[datetime]`) сохраняются.
- **Форматы**: Markdown (заголовки по сообщениям), JSON (структурированный
  массив с метаданными), TXT.
- **Скачивание**: `<a download>` из content script — гарантированный путь без
  дополнительных разрешений. Payload также доступен в popup через
  «Скопировать текст» (буфер обмена, без файла).
- **Авто-инжекция**: если вкладка была открыта до установки расширения,
  popup/hotkey сами подгрузят content script (`chrome.scripting`) — обычно
  без обновления страницы (F5 — запасной вариант).
- В popup есть переключатель «Прокручивать историю» (для быстрого экспорта
  только видимой части).

## Состав

| Файл | Роль |
|---|---|
| `manifest.json` | MV3-манифест: права (`scripting` — только авто-инжекция), host z.ai, content script, хоткей |
| `content.js` | Ядро экспорта + хронология + плавающая кнопка + приём команд от popup/hotkey |
| `background.js` | Service worker: хоткей + авто-инжекция content script (без скачивания) |
| `popup.html` / `popup.js` | Popup: выбор формата, статус, автопрокрутка, «Скопировать текст» |
| `icons/` | Иконки 16/48/128 (генерируются `build-icons.py` при изменении) |
| `build-icons.py` | Пересборка иконок (PIL) — в zip не входит |

## Troubleshooting

| Симптом | Решение |
|---|---|
| Popup: «нет ответа от вкладки» | Расширение установлено после открытия чата — обновите страницу (F5). |
| «Сообщений собрано: 0» | DOM Z.ai изменился: подстройте `MESSAGE_SELECTORS` в `content.js` (блок CONFIG в начале). |
| Собрано меньше, чем видно | Увеличьте `SCROLL_SETTLE_MS` (медленная подгрузка) в CONFIG. |
| Часть сообщений `unknown` | Уточните `USER_HINT` / `ASSISTANT_HINT` в CONFIG. |
| Хоткей не работает | `chrome://extensions/shortcuts` → назначить вручную. |

## Приватность

Расширение не отправляет данные никуда, кроме вашего браузера: content script
собирает текст сообщений и сохраняет файл локально через `<a download>`; единственная
передача payload — в popup для кнопки «Скопировать текст» (внутри того же браузера).
Никаких внешних запросов, аналитики и телеметрии — проверяется по исходникам
(три небольших JS-файла без зависимостей).
