# Z.ai Chat Export

Инструменты для скачивания **всего текста чата Z.ai** в файл (Markdown / JSON / TXT).
Работают на стороне браузера — у агента нет API-доступа к вашему аккаунту Z.ai,
поэтому единственный надёжный канал экспорта — это скрипт, исполненный в вашей сессии.

## Состав

| Файл | Что это | Когда использовать |
|---|---|---|
| `zai-chat-export-console.js` | Скрипт для вставки в консоль DevTools | Разовый экспорт, самый быстрый способ |
| `zai-chat-export.user.js` | Tampermonkey-плагин (userscript) с кнопкой «Export chat» | Регулярные экспорты, всегда под рукой |
| `chrome-extension/` | **Chrome-расширение (MV3)**: кнопка + popup + хоткей Ctrl+Shift+Y, хронология «от начала до конца», скачивание через `<a download>` | Самый удобный способ для Chrome (см. `chrome-extension/README.md`); zip-пакет (в корне репо): `download/zai-chat-export-chrome-extension.zip` |
| `test/mock.html` | Мок чата с lazy-load для тестов | Проверка скрипта без реального чата |

## Способ 0 — Chrome-расширение (рекомендуется)

1. Скачайте/распакуйте `download/zai-chat-export-chrome-extension.zip`
   (путь от корня репозитория `/home/z/my-project`) в постоянную папку
   (или используйте каталог `chrome-extension/` как есть).
2. Откройте `chrome://extensions` → включите **Developer mode** (справа вверху).
3. **Load unpacked** → выберите папку с `manifest.json`.
4. Откройте чат `chat.z.ai`:
   - кнопка **«Export chat»** внизу справа (клик = .md, Shift+клик = .json, Alt+клик = .txt);
   - иконка расширения → popup: формат, тумблер авто-прокрутки, «Скопировать текст»;
   - хоткей **Ctrl+Shift+Y** (Cmd+Shift+Y на Mac) — мгновенный экспорт в Markdown.

Подробности — в `chrome-extension/README.md`.

## Способ 1 — консоль (без установки чего-либо)

1. Откройте нужный чат в Z.ai.
2. Нажмите `F12` → вкладка **Console**.
   - Chrome при первой вставке попросит набрать `allow pasting` — наберите эту
     строку в консоли, Enter, затем вставляйте скрипт.
3. Вставьте **всё содержимое** `zai-chat-export-console.js` и нажмите Enter.
4. Скрипт сам прокрутит историю вверх (подгружая старые сообщения), соберёт
   все сообщения и скачает файл `zai-chat-<id>-<дата>.md`.

Программный доступ к результату (без скачивания):

```js
__ZAI_CHAT_EXPORT.payload          // текст файла
__ZAI_CHAT_EXPORT.messageCount     // сколько сообщений собрано
__zaiExportChat({ FORMAT: 'json', DOWNLOAD: false })  // другой формат, без скачивания
```

## Способ 2 — плагин Tampermonkey

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Firefox).
2. Tampermonkey → Dashboard → «+» → вставьте всё содержимое `zai-chat-export.user.js` → Ctrl+S.
3. Откройте Z.ai — внизу справа появится кнопка **Export chat**:
   - клик → `.md` (Markdown)
   - Shift+клик → `.json`
   - Alt+клик → `.txt`

## Как это работает

1. Поиск сообщений: каскад селекторов (`[data-message-id]`, `[data-testid*=message]`,
   `[class*=message]`, `[class*=chat-item]`, `[class*=bubble]`, `article`)
   с фильтрацией контейнеров и невидимых узлов.
2. Определение роли (User/Assistant): атрибуты `data-role` / классы
   (`user|human|self` vs `assistant|bot|ai|markdown|prose`), затем выравнивание
   (flex-end → User). Нераспознанные помечаются `Unknown`, не выбрасываются.
3. Прокрутка вверх до исчерпания истории (детект «нет роста 10 шагов подряд»),
   с накоплением в Map по стабильному id — **дружит с виртуализацией DOM**:
   даже если сообщения удаляются из DOM при прокрутке, они уже сохранены.
4. Сохранение код-блоков (`pre` + язык из `language-*`) и временных меток (`time[datetime]`).
5. **Хронологический порядок** («от начала до конца»): после загрузки всей истории —
   пересборка в DOM-порядке + сортировка по timestamp (если парсится >=80% меток);
   иначе lazy-load дописывал старые блоки после новых.
6. Сериализация и скачивание через Blob; позиция скролла восстанавливается.

## Troubleshooting

| Симптом | Причина и решение |
|---|---|
| `Сообщений собрано: 0` | Селекторы не подошли к DOM. Откройте консоль, выполните `document.querySelector('[data-message-id],[class*="message"]').className` и добавьте актуальный класс в `CONFIG.MESSAGE_SELECTORS` (блок в начале файла). |
| Собрано меньше, чем видно в чате | Увеличьте `MAX_SCROLL_STEPS` / `SCROLL_SETTLE_MS` в CONFIG (медленная сеть → дольше подгрузка). |
| `unknown` у части сообщений | DOM без явных признаков роли; поправьте `USER_HINT` / `ASSISTANT_HINT`. |
| Скачивание не началось | Возьмите текст из `window.__ZAI_CHAT_EXPORT.payload` и сохраните вручную. |
| История бесконечно грузится | Уменьшите `MAX_SCROLL_STEPS` (предохранитель сработает сам). |

## Ограничения и приватность

- Z.ai может изменить DOM — селекторы конфигурируемы в блоке `CONFIG` в начале обоих файлов.
- Если в чате есть чувствительные данные (токены, пути к секретам) — **не публикуйте
  экспорт** в общедоступные места; в этой рабочей линии принято правило «секреты не
  печатаются и не логируются» — экспортированный файл обрабатывайте так же.
- Проверьте также встроенные механизмы Z.ai (кнопка Share/экспорт в UI), если
  они появились — они могут отдать историю без скрипта.

## Тестирование (выполнено 2026-09-26, agent-browser + mock.html)

- Mock-чат: 10 сообщений в DOM + 10 подгружаются lazy-load при прокрутке вверх,
  дубликаты id, код-блок `language-js`, `time[datetime]`.
- Результаты: собрано ровно 20/20 уникальных; роли 10 User / 10 Assistant / 0 Unknown;
  порядок строго хронологический (`dom+time`, первое = начало чата); код-блок
  сохранён; дедуп по `data-message-id` подтверждён; MD/JSON/TXT все три формата
  корректны; userscript: кнопка монтируется, клик экспортирует; Chrome-расширение
  v1.0.1 (объединённая версия): `via: anchor`, `order: dom+time`, порядок
  хронологический, manifest/JS валидны.
