Education — беседы рядом
Неофициальное расширение собственного сайта, не продукт OpenAI.

Требуется Chrome 155+ с tabs.createSplit.
1. Распакуйте архив в постоянную папку.
2. Откройте chrome://extensions, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение», выберите эту папку.
4. На https://devfleet-education-web.vercel.app обновите страницу и нажмите «Подключить рядом».
5. Войдите в настоящий ChatGPT самостоятельно. Выберите нужную доступную модель в его меню.
6. После первого отправленного вами сообщения URL беседы закрепится за темой.
7. Переключайте темы слева: рядом появляется отдельная вкладка соответствующей беседы.

Расширение использует штатный Split View Chrome. Оно не встраивает ChatGPT в iframe,
не отключает защиту браузера, не читает сообщения, пароли, cookies или API-ключи.
Содержимое урока копируется отдельной кнопкой сайта; расширение ничего не отправляет.
Модель выбирает пользователь; расширение не подтверждает GPT-6 Pro по одному названию.

Хранятся URL бесед и идентификаторы связанных вкладок. При переключении вкладки
не закрываются и беседы не удаляются. Если вручную сменить беседу в привязанной
ChatGPT-вкладке, работа с ней приостанавливается. Закройте только эту вкладку и
снова откройте чат урока. Неизвестный результат создания не повторяется автоматически.
Одновременно поддерживаются 24 открытые вкладки чатов на одно учебное окно;
сохранённые привязки доступны для всех 120 тем.

После смены аккаунта ChatGPT старые ссылки могут быть недоступны: идентификатор
аккаунта не читается. Ошибки и отсутствие авторизации не выдаются за успех.
Автоматическое редактирование страницы урока из веб-чата не подключено.
