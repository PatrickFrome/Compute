# METAENGINE Browser Shell V3 product contract

The Browser shell is intentionally calm by default.

- Light is the primary visual mode for this candidate.
- The active web page owns the center and receives the largest stable native WebContents rectangle.
- Contexts remain visible on the left; Brain remains closed until explicitly requested.
- Persistent chrome exposes one omnibox, one compact health cluster, Brain, and New.
- Deep Fleet, Supervisor, DevOS, Runtime, Safety, and command evidence remains reachable but is not permanent dashboard chrome.
- UI presentation does not create command authority, retry authority, or renderer geometry authority.
- No decorative perpetual animation loop is permitted.
- The design vocabulary is rounded, quiet, low-contrast, keyboard-friendly, and context-first.
