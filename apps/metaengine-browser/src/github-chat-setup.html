Управление клиентом и ПК из чата

Привяжите отдельный приватный репозиторий GitHub к этому компьютеру. Чат и его агенты смогут видеть окна и экран, управлять приложениями и браузером, ставить задачи и получать результаты.

Включите Issues и предоставьте подключённому GitHub-приложению чата доступ к этому репозиторию. Нужны Metadata: read, Issues: read/write и Contents: read/write. Токен вводится только здесь и сохраняется защищённым на этом ПК.

Нажимая «Подключить», вы разрешаете управление до отзыва доступа, без повторных запросов на каждое действие. Привязка работает через локальный PostgreSQL и API.
