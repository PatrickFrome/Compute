Safe possible future interface; not implemented by this review
Use only an original authenticated native Main/Host composition, exposing a
private zero-argument, bounded operation that reads OS directories directly
(as the GetSystemDirectoryW callers already do) and remains scoped to the same
original native lifetime. Any required Windows-directory root needs its own OS
API reading rather than an environment-derived drive. Preserve native file,
ancestor, image and identity verification. An arbitrary callback/path, public
JSON/config/environment field, helper receipt or copied object cannot mint the
producer. A root path alone is not loaded-code custody or execution authority.
Until that producer exists and is qualified, other system roots remain HOLD.
