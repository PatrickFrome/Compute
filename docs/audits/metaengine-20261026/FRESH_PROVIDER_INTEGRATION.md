- Electron sandbox and privileged scheme setup occur synchronously before asynchronous first-run setup and before `app.whenReady()`.
- Existing parent suspension protocol checkpoints read-only work and releases capacity under exact lease/custody fences. Resume restores the original conversation. Task-local holds do not stop unrelated parents; global authentication and integrity failures remain global.
- Verified skills are fixed immutable advisory checklists for critic/falsifier roles. Observation data does not grant task acceptance, execution authority, or measured learning credit.
- Offline source closure includes the exact native identity adapter and reviewed Browser dependencies; no private test loader is packaged. The sole Electron builtin exception is path-specific and byte-pinned. The catalog has 21 migration entries and 57 public RPC signatures, excluding private owner approval.
